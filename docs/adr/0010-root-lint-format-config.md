# ADR-0010: Корневые конфиги линта и форматирования

- Статус: Предложено
- Дата: 15.11.2026
- Кто решил: предложил агент по поручению пользователя
- Связано: [ADR-0007](0007-oxlint-oxfmt.md), [README](../../README.md)

## Контекст

Общие правила находились в `packages/oxlint-config`, корневой конфиг
наследовал их, а конфиг web подключал корневой и ещё один пресет.
Это усложняло изменение правил и приводило к разному поведению команд:
корневой запуск применял правило Next.js для `<img>` к API и не учитывал
браузерное окружение web. Регрессионные тесты воспроизвели обе проблемы.

## Решение

Для одного репозитория используем один корневой `.oxlintrc.json`:
общие правила, исключения, проверка типов, нулевой лимит предупреждений
и `overrides` для отличий. Плагин и правила Next.js действуют в `apps/web`,
браузерное окружение включено для web и `packages/ui`.
Конфигов Oxlint в приложениях и пакета `oxlint-config` нет.

Oxfmt сохраняет один корневой `.oxfmtrc.json`. Инструменты и JS-плагин
Turborepo устанавливаются в корне. Команды `lint` в приложениях и пакетах
явно передают корневой конфиг и проверяют текущую папку; `pnpm lint`
проверяет весь репозиторий. Steiger остаётся отдельной проверкой web,
доступной из корня через `pnpm lint:fsd`. Версии и строгость общих правил
сохраняются. Решение дополняет ADR-0007, выбор инструментов не меняет.

## Рассмотренные варианты

- Пакет общих пресетов и конфиги приложений: полезны для независимого
  переиспользования, но здесь добавляют зависимости и уровни наследования.
- Независимые конфиги приложений: копируют общие правила и допускают
  расхождение между локальной проверкой и запуском из корня.

## Последствия

Правила редактируются в двух корневых файлах. Новый пакет наследует общий
линт; отличия добавляются в `overrides`. Изменение правил не требует
перестройки отдельного пакета конфигурации. Корневые конфиги остаются
зависимостями кэша Turborepo. При переносе были проверены общие правила,
типы, Next.js, окружения, JS-плагин и исключение результатов сборки
при запуске из корня и из пакетов.

## Что меняется для агентов

В корневом AGENTS.md указаны `.oxlintrc.json`, `.oxfmtrc.json`
и `overrides` как места настройки. Новый пакет конфигов и локальные
копии правил не создаём. Общий TypeScript-конфиг остаётся отдельным пакетом:
его наследуют `tsconfig.json` приложений и библиотек.

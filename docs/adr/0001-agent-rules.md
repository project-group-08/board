# ADR-0001: Единые правила для ИИ-агентов

- Статус: Предложено
- Дата: 11.11.2026
- Кто предложил: фронтенд; решение принимает команда на ревью PR
- Связано: [архитектура фронтенда](../architecture/frontend.md), [docs/ai/README.md](../ai/README.md)

## Контекст

Команда пишет код с разными ИИ-агентами: Claude Code, Codex, Cursor, Copilot и другими. У каждого свой формат инструкций и своё место для скиллов. Без общего источника правила разъезжаются, а агент пишет код по памяти: старые версии API, чужая структура папок, middleware.ts вместо proxy.ts.

## Решение

- Единый источник правил: `AGENTS.md` в корне и в каждом приложении и пакете. Его читают Codex, Cursor, Copilot, Antigravity, Devin и Claude Code.
- Рядом с каждым `AGENTS.md` лежит `CLAUDE.md`, который начинается со строки `@AGENTS.md`. Так Claude Code видит правила в любом режиме, даже если у разработчика есть личный `CLAUDE.local.md`.
- Скиллы проекта (многошаговые процедуры) лежат в `.agents/skills/` по стандарту agentskills.io; для Claude Code в `.claude/skills/` симлинки на те же папки. Имена латиницей с общим префиксом `project-`, чтобы скиллы проекта легко отличить от личных; свои скиллы так не называют.
- Знания о фреймворках агент берёт из документации установленной версии: в AGENTS.md указатели на неё (node_modules и llms.txt). Скиллы вендоров подключаем выборочно, когда появится каркас.
- Правила без исключений проверяет автоматика: oxlint, oxfmt, Steiger, TypeScript, хук Git перед пушем и CI. Запреты в `.claude/settings.json` дополнительно ловят типичные опасные команды Claude Code. В AGENTS.md о них только упоминание.
- Коммиты по Conventional Commits с описанием на русском; комментарии в коде на русском.

## Рассмотренные варианты

- Только `CLAUDE.md`: остальные агенты его не читают или читают частично.
- Симлинк `CLAUDE.md` на `AGENTS.md`: на Windows без `core.symlinks` git выкачивает его однострочным текстом, а Claude Code не пишет через симлинк.
- Правила Cursor (`.cursor/rules`) и Copilot (`.github/instructions`): работают только в своём инструменте, дублируют AGENTS.md.
- Все знания о фреймворках скиллами: агент часто не вызывает скилл сам; указатель на документацию в AGENTS.md надёжнее.

## Последствия

- Корневой AGENTS.md короче 200 строк, а вместе с самым длинным AGENTS.md пакета меньше 32 КиБ: Codex отбрасывает файлы сверх этого лимита.
- Симлинки скиллов на Windows требуют `core.symlinks=true`; без них Claude Code не увидит скиллы.
- AGENTS.md меняем в PR вместе с кодом. Агент дважды ошибся одинаково: добавляем правило.

## Что меняется для агентов

Появляются корневой AGENTS.md, AGENTS.md пакетов, скиллы `project-*` и запреты в `.claude/settings.json`.

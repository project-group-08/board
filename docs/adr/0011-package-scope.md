# ADR-0011: Пространство имён пакетов Tabula

- Статус: Предложено
- Дата: 15.11.2026
- Кто решил: предложил агент по поручению пользователя
- Связано: [ADR-0002](0002-monorepo.md), [AGENTS.md](../../AGENTS.md)

## Контекст

Пользователь поручил использовать имя продукта Tabula в названиях внутренних
пакетов вместо общего префикса.

## Решение

Внутренние пакеты называются `@tabula/<папка>`. То же пространство имён
используется в зависимостях workspace, импортах, наследовании TypeScript,
фильтрах pnpm и генераторе каркаса. Внешние зависимости и их версии сохраняются.

## Рассмотренные варианты

- Сохранить общий префикс: названия пакетов не отражают имя продукта.
- Использовать разные префиксы: усложняет поиск и создание новых пакетов.

## Последствия

После переименования нужна установка зависимостей для обновления локальных
ссылок и lockfile. Каталоги пакетов, их границы и публичные протоколы остаются
прежними.

## Что меняется для агентов

В корневом AGENTS.md и генераторе каркаса используется `@tabula/`.
Документация и команды приложений обновляются вместе с манифестами.

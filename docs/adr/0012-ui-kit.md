# ADR-0012: Base UI и структура UI Kit

- Статус: Предложено
- Дата: 16.11.2026
- Кто решил: команда — выбор Base UI; структура UI Kit предложена для согласования
- Связано: перенос UI Kit, архитектура фронтенда

## Контекст

Общему интерфейсу нужны согласованные примитивы и структура компонентов с тестами и stories.

## Решение

Основа интерактивных примитивов — Base UI. Нативные компоненты не переписываем без необходимости. В `shared/ui` для каждого компонента выделена отдельная папка с реализацией, тестом, story и собственным `index.ts`. Папки и файлы называются в kebab-case; общего `shared/ui/index.ts` нет. Токены UI Kit — источник истины.

## Рассмотренные варианты

- Radix: команда выбрала Base UI.
- Один файл на компонент: выбран комплект в отдельной папке, как в UI Kit.

## Последствия

Перенос требует зависимостей Base UI и инфраструктуры тестов и Storybook. Выгрузку архитектурной доски обновляет архитектор фронтенда после изменения доски.

## Что меняется для агентов

Правила выбора основы и раскладки `shared/ui` обновлены в `apps/web/AGENTS.md`; вопрос основы удалён из открытых в корневом `AGENTS.md`.

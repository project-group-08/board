# Ревью изменений

Собери дифф: `git fetch origin develop`, затем `git diff origin/develop...HEAD`, или изменения PR. Форматирование, порядок импортов и всё, что ловят oxlint, oxfmt и Steiger, не обсуждай: это проверяет CI.

## Что проверить

1. Границы: слой FSD импортирует только слои ниже; чужой слайс только через `index.ts`; пакеты импортируют друг друга по схеме из корневого AGENTS.md; `apeiro` только в `apps/web` ([ADR-0013](../../../docs/adr/0013-apeiro-board-engine.md)).
2. Контракты: данные между web, api и worker описаны схемой в contracts, тип через `z.infer`; изменение совместимо (только добавление) или есть ADR.
3. Состояние: данные сервера в TanStack Query; документ доски меняется только через движок; присутствие и камера не в Y.Doc; Zustand только для интерфейса, стор через контекст.
4. Доска и производительность: движение курсора и жесты не вызывают перерисовку React; подписки на движок по id через `useSyncExternalStore`; перерисовка холста через один `requestAnimationFrame`.
5. Синхронизация: свои транзакции с origin `LOCAL`; отмена только своих; повторная доставка не создаёт дублей; после обрыва связи досинхронизация в обе стороны.
6. Права и безопасность: права проверяет бэк в каждом HTTP-запросе и событии сокета; секретов нет в `apps/web` и `NEXT_PUBLIC_*`; входные данные проверяются схемой.
7. Next.js: маршрут только ре-экспортирует страницу; серверный код через `index.server.ts`; доска только на клиенте; `proxy.ts` не единственная проверка прав.
8. Тесты: новое поведение покрыто; баг закрыт тестом; LLM, Telegram, S3 и почта в тестах замоканы, Sentry без DSN.
9. Процесс: правки не выходят за задачу; коммиты по Conventional Commits с описанием на русском; комментарии про «почему»; вопросы из списка «Ещё не решено» не решены молча.

## Как писать замечания

- Одно замечание на проблему: файл и строка, что не так, какое правило нарушено, как исправить.
- Важность: «блокирует» (ошибка или нарушение правила), «стоит поправить», «на выбор».
- По пункту без проблем ничего не пиши.
